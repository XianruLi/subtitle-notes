# 使用指南（日常怎么用）

## 0. 它怎么工作（30 秒看懂）

```text
你往一个文件夹里丢文件  →  它自己出 Markdown 笔记
D:\personal_proj\视频字幕\           →  D:\personal_proj\daemons\output\
```

**关键**：它靠"监听"工作。监听开着的时候，丢文件就自动处理，**不需要跑 python**；
监听没开的时候，才需要手动跑一次（见第 1 节）。

## 1. 先把监听开起来（选一种，日常用第一种）

| 方式 | 怎么做 | 适合 |
|------|--------|------|
| **常驻监听（推荐）** | 双击项目根目录的 启动监听.bat，黑窗口最小化别关 | 丢文件就自动出笔记 |
| **界面常驻** | 双击 dist\SRTDaemon\SRTDaemon.exe → 任务页「启动监听」→ 关窗口会最小化到托盘 | 想顺便看进度/日志 |
| **一次性处理** | python -m src.srt_daemon.main --scan | 平时不开，偶尔批量跑 |

> **监听只吃字幕文件**（.srt/.vtt）。录音/视频默认走「新建任务」页手动处理，
> 因为只有那里能指定说话人数量、类型和模型——监听不会替你瞎猜然后白跑一小时。
> 想恢复完全自动转录：config.yaml 里 transcribe.auto_transcribe_media 改成 true。

### 让它开机自动监听（配置一次，以后彻底不用管）

界面 → **设置 → 窗口与启动 → 勾选「开机自动启动」**，同时确认「启动后自动开始监听」已勾选 → 保存。

以后登录 Windows 它就在托盘里自动监听，你只要往监听目录丢文件即可，**永远不用再开程序**。

## 2. 日常四种用法

### ① 有视频 + CC 字幕（YouTube 插件导出的）——最快

把**两个文件放进监听目录**（D:\personal_proj\视频字幕\）：

```text
lecture.mp4         视频
lecture.en.vtt      插件导出的字幕（带语言后缀也能配上）
```

→ 几十秒出笔记，**不会转录视频**（省几十分钟）。视频只用于截图。

**如果你把这对文件放在项目文件夹里**（不想搬进监听目录）：
界面 → 新建任务 → 「本地字幕 → 笔记」→ 选那个 .srt / .vtt → 选「笔记类型」
（比如采访）→ 生成笔记。同目录同名视频会**自动**被用作截图，不需要额外操作。

**整个文件夹一起做**：同一张卡片点「添加文件夹…」，选一个文件夹后递归处理里头
所有 .srt/.vtt（一个失败不会中断其余）。命令行等价写法：

```powershell
python -m src.srt_daemon.main --once "D:\下载\某门课" --profile course
```

如果不想搬文件，也可以原地处理：

```powershell
cd D:\personal_proj\daemons
python -m src.srt_daemon.main --once "D:\其它目录\lecture.en.vtt"
```

### ② 只有字幕（srt / vtt）

丢进监听目录即可，秒级出笔记。

### ③ 只有视频 / 录音（走「新建任务」页，参数全可控）

界面 → **新建任务** → 「音频 / 视频 → 字幕」：

1. 选择文件（或整个文件夹）
2. 设 **说话人数**（如会议 3 人；空 = 自动聚类）、**姓名映射**（1=张三,2=李四）、
   **模型**、**语言**
3. 选 **笔记类型**（auto / 课程 / 会议 / 访谈）
4. **需要笔记才勾**「转录后自动生成笔记」

> 字幕与笔记都写在**所选媒体所在的文件夹**（`transcribe.output_beside_source`），
> 不会进监听目录，所以不勾就不会顺带生成笔记。想统一放进监听目录：
> 把该开关设为 false，或命令行加 `--output-dir`。

→ 一次搞定：转录 + 出笔记。命令行等价写法：

```powershell
python -m src.srt_daemon.main --transcribe "会议录音.mp3" --num-speakers 3 --speakers "1=张三,2=李四" --notes --profile meeting
```

| 20 分钟录音 | CPU 耗时 |
|---|---|
| small | ≈ 12 分钟 |
| medium | ≈ 22 分钟 |
| **large-v3（默认）** | ≈ 50 分钟 |

**默认不降级**：无论多长都用你配置的模型（large-v3）。想长音频自动换快模型，
把 config.yaml 里 transcribe.long_media.enabled 改成 true（阈值 30 分钟、模型 medium 可调）。
临时换模型：界面「新建任务」里选，或命令行 --model medium。

### ④ 在线链接（B站 / YouTube）

界面 → **在线视频** → 粘链接 → 「解析」（会显示标题/时长/分P/字幕情况）→ 选分P → 「生成笔记」。

## 3. 结果在哪

```text
daemons/output/<字幕名>/
  <字幕名>_笔记_日期.md      笔记正文（front matter 记录了来源、模型、profile、说话人数）
  images/shot-000321.jpg     截图（如果开了截图且有视频）
```

同一个文件不会重复处理（按文件内容哈希记录）。想重跑：把文件改一下（内容变了哈希就变），
或删掉 output/<名字>/ 并把 output/.processed.json 里对应条目删掉。

### 笔记放在哪里（设置 → 路径 → 保存位置）

| 选项 | 笔记位置 | 适合 |
|------|----------|------|
| **集中目录（output/）** | D:\personal_proj\daemons\output\<名字>\ | 统一管理，任务页「最近生成的笔记」自动列出 |
| **与源文件同目录** | <字幕或视频所在文件夹>\<名字>\（含 images/） | 笔记跟着项目走，一项目一文件夹 |

切换到「与源文件同目录」后：别处的字幕（例如 D:\projects\收纳\talk.srt）
会在该文件夹下生成 talk\ 子目录，笔记与截图都在里面；在线视频（URL）的笔记
仍然写到集中目录。

## 4. 只需要配置一次的东西

| 文件 | 里面有什么 | 什么时候要改 |
|------|-----------|--------------|
| .env | DEEPSEEK_API_KEY | 换 key 时 |
| config.yaml | 监听目录、模型、截图开关、长音频降级 | 想换目录 / 换模型 / 开截图 |
| gui_settings.json | 界面偏好（主题、托盘、自启） | 不用手动改 |

**截图已开启**（screenshots.enabled: true）：笔记会在 AI 标注的位置自动插入画面，
图片放在笔记同级的 images/ 目录。

**截图数量按视频时长自动决定**（设置 → 截图，或 config.yaml 的 screenshots 段）：

```yaml
screenshots:
  dynamic_count: true   # 按时长决定张数
  per_minute: 0.5       # 20 分钟 → 10 张；90 分钟 → 45 张（再被 max_count 截断）
  min_count: 3          # 短视频至少 3 张
  max_count: 40         # 每篇硬上限
```

不是"每 N 分钟机械截一张"：模型仍自己挑值得看的时刻，时长只决定**数量区间**
（例如 20 分钟的视频会要求模型输出 6–10 个标记）。不想要就在界面「设置 → 截图」取消，或把 config.yaml 改成 false。
本地视频/同名视频截图零成本；在线视频要截图才会额外下载视频。

## 5. 常见问题

**丢了个视频/录音进文件夹没反应？**
正常——监听默认只处理字幕文件。录音/视频请用「新建任务」页（能设人数与类型），
或把 transcribe.auto_transcribe_media 打开。

**丢进文件夹没反应？（字幕）**
1. 监听没开（第 1 节）
2. 文件不在监听目录里，或者在**子文件夹**里（监听只扫一层）
3. 这个文件以前处理过，内容没变

**转录很慢？**
换成 small / medium；或确认有 NVIDIA 显卡时 device: auto 已生效（日志里会写 device=cuda）。

**笔记里没有截图？**
截图开关没开，或者没有对应的视频（只有字幕时不会有图）。

**B站 说没有字幕 / 字幕对不上？**
有的视频没有 CC，或 B站 的 AI 字幕只覆盖一小部分（程序会拒绝 <60% 的字幕并改为转写）。

**想看它到底在干什么？**
界面「日志」页，或 daemons\logs\srt-daemon.log。

## 6. 命令速查（真正常用的）

```powershell
# 常驻监听（等于双击 启动监听.bat）
python -m src.srt_daemon.main

# 扫一遍监听目录，处理完退出
python -m src.srt_daemon.main --scan

# 只处理一个文件（指定类型）
python -m src.srt_daemon.main --once "D:\a\lecture.srt" --profile course

# 打开界面
python -m src.srt_daemon.app

# 手动转录（不进监听目录，直接指定文件/文件夹）
python -m src.srt_daemon.transcribe "D:\videos\meeting.mp4" --model medium
python -m src.srt_daemon.transcribe --dir "D:\videos" --recursive --list

# 在线视频（命令行版）
python -m src.srt_daemon.fetch --dry-run "https://youtu.be/xxx"
python -m src.srt_daemon.fetch "https://www.bilibili.com/video/BV..."
```

```text
daemons\logs\                       ← 日志
daemons\cookies\bilibili.txt         ← B站 登录态（CC 字幕用）
daemons\models\                     ← 说话人聚类模型
daemons\src\srt_daemon\          ← 源码
daemons\doc\                        ← 文档（本指南、流程图、运维手册）
daemons\dist\SRTDaemon\          ← 打包版 exe
```
